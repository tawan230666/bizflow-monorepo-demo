# BizFlow — Franchise Dashboard (UI prototype)

A design prototype of a multi-branch analytics dashboard for franchise owners: branch comparison, finance breakdown, customer reports and branch accounts, with light/dark mode.

> **Status:** front-end prototype using mock data. It is not yet connected to the API server.

Google sign-in is optional: set your OAuth client ID in `src/pages/LoginPage.tsx` to enable it.

```bash
npm install
npm run dev            # http://localhost:3001
```
